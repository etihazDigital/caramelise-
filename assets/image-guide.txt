CARAMÉLISÉ WEBSITE — IMAGE GUIDE
================================
This file lists every image used on the website, where it appears, and the
recommended size/orientation — so real product photography can be dropped in
later using the SAME file name (no code changes needed if the new photo has
a similar shape).

NOTE: These 20 images are placeholder / inspiration photos (not verified to
be Caramélisé's own product photography) — used here purely to build out the
layout beautifully. Swap them for the client's real photos when ready, using
the exact file names below so nothing breaks.

HOW TO REPLACE AN IMAGE LATER
--------------------------------
1. Prepare the client's real photo (JPG, ~1000–1600px on the longer side,
   compressed to keep the site fast — 100–300KB per image is a good target).
2. Rename it to match exactly one of the file names above.
3. Drop it into this "assets" folder, overwriting the placeholder.
4. Refresh the site — no HTML/code edits needed since the file name stays
   the same.
